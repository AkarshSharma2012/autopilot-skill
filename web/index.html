Follow the work.

● Files stay in your browser

Inspect a signed receipt, an embedded PNG receipt, or an attribution marker. A missing receipt means the origin is unknown.

PNGs can carry embedded receipts. Screenshots and edited images often lose metadata; appearance alone cannot prove origin.

Whitespace and line endings count. An AP1 marker without its signed receipt is attribution only.

GitHub repositories need a published .autopilot/provenance.json. Other URLs must allow browser access (CORS). Private repositories are unsupported; no login tokens are requested.

Trust a known signer optional

Never paste a private key. A key carried in the receipt is self-signed until you match it with a key you already trust.

What a result actually means

Trusted receipt

Matching bytes and a valid signature from a public key you supplied independently. The workflow claim is still the signer’s declaration.

Self-signed or marker only

A signed claim from an unknown signer, or a visible attribution marker. Neither independently proves Autopilot use.

Unknown or changed

No usable receipt, inaccessible content, or bytes that differ. Missing provenance is never proof that Autopilot was not used.
